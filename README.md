## スキル一覧
- **アクロバット**: スニークでジャンプ強化、落下ダメージ無効
- **スカウト**: グラップリングフック移動、俊敏付与
- **ガーディアン**: 最大体力アップ、再生付与
- **ブリンク**: 短距離ダッシュ移動（着地後リチャージ）
- **ブラストパック**: 投擲→起爆で吹き飛ばし移動
- **テレポート**: ビーコン設置後に転送 / フェイク発動
- **ダッシュ**: エネルギー制の高速移動＋スライド

## 使い方
1.  `/skill` コマンドを打つ
2. スキルを選ぶ

## 権限
- `skills.use` (既定: 全員): `/skill` を使う

## 配布されるアイテム
スキルで使うアイテムは、選択したときに1つだけ配布されます。スキルを変更したり、サーバーから退出したりすると回収されます。
落としたり、容器に入れたり、クラフトに使ったりすることはできません。死亡すると失われ、リスポーン時にもう一度配布されます。
